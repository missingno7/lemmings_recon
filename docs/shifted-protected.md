# Shifted protected planar body

The native core for `PlanarShiftedMasked8000Body` covers the body at `8B42..8D64`. Its boundary adapter consumes the unchanged `RETF` at `8D65`. The physical range through the adapter is 548 bytes; 547 bytes precede the far return. The known body has 305 instruction sites and 42 observed direct branch edges. `UNKNOWN` byte `8CF4` remains outside C accounting and is preserved as stored.

The only discovered static incoming edge is `88F9 -> 8B42`; there are no calls or outgoing direct edges in this body. These facts set a physical review boundary, not a complete indirect or modified-code entry domain. The normal branch at `8CF2` jumps over `8CF4` to the shared `POP DS`; the UNKNOWN classification remains unresolved, and this does not establish that the byte is dead.

At entry, the body decrements the active destination row advance through incoming `DS:6704`, then saves DS and loads the graphics source segment through incoming `DS:1FE4`. `MOV AX,09A9` uses a relocation and loads the supplied game-data segment into ES. The swapped DX bytes put the original high byte into BP as the plane count; after setup, DX is the live VGA port value. The body never reads or writes BX.

The VGA setup selects plane 0, set/reset data 0 with set/reset disabled, logical OR, read mode 1, color care 08, and compare value 08. A read from `A000:DI` loads the latches and compares plane 3. `NOT AH` turns that comparison into a mask for bits where plane 3 is clear. Each byte then programs the mask through the live `SS:000E` mirror and VGA port, reads source data with LODSB, and writes it through STOSB. The three later passes change the Sequencer map mask to planes 1, 2, and 3. Writes use the fixture’s VGA latch and bit-mask merge behavior.

Each row first copies `CL` bytes from live `DS:SI` to game-segment scratch at `6706` with REP MOVSB, then writes a zero sentinel. Both operations follow DF. The body switches DS to the saved ES scratch segment, sets ES to A000, and reads the unchecked shift byte at `DS:A948`. Each shift pass applies SHR to the first scratch byte, then RCR to the following `CL` bytes. SI advances forward through the carry chain; INC preserves CF between RCR operations. A zero shift byte wraps the DEC loop to 256 passes. After shifting, the draw loop processes `CL+1` bytes, so CL zero runs 65,536 iterations and CL FF wraps to a 65,536-iteration loop. LODSB and STOSB follow DF; the VGA mask/scratch increment chain remains forward.

Rows read live `DS:6702` and `DS:6704` for their source and destination advances. The entry decrement uses the caller’s initial DS, while row work uses the live segment restored from ES. The source plane advance comes from live `ES:66F8`. SS stack saves, source scratch, shift fields, row fields, and cursors can alias one another; the core performs pushes, pops, and memory accesses on the same 20-bit RAM image so those aliases remain visible.

After the first, second, and third plane passes, BP is decremented and tested. A zero input plane count underflows and still reaches four passes; counts above four also stop after the fourth pass. The fourth pass has no BP test or decrement. The first three passes save and restore their plane cursors and counts. The fourth leaves the last row’s live SI, DI, CX, DS, ES, and AX values for the adapter. CLI and STI remain per row, with STI setting IF even if incoming IF was clear.

`tests/shifted_protected.py` runs 20 bounded constructed cases against the relocated original routine. It covers all 305 core sites and 42 direct branch edges, checks full RAM, all relevant registers, defined flags, ordered RAM/VGA bus events, and plane/latch/register state. Independent expectations check the shifted scratch bytes and plane-3 protection footprint. Cases cover plane counts 0 through 5 and FF, DF, shift counts 0 through 7, zero CL/CH and CL FF loops, 20-bit and SP wrap, distinct incoming/game DS, and live stack/scratch aliases, including a finite SS=A000 fixture seeded through plane 3. Three compiled mutants for dropped carry, ignored DF, and a fourth BP decrement are detected.

Three isolated probes compare the unchanged RETF with the adapter. Those probes exclude VGA-backed stacks, wrapped SP, and live SS/save aliases: Unicorn’s reads after removing the original device hook cannot preserve the device view and stack/frame alias state. Every native call runs through `run_bounded` with a 180-second timeout, 512 MiB per-process commit limit, a 768 MiB Windows process-tree commit limit, one-million bus-event cap, 300,000 VGA trace cap, and an eight-million-instruction original limit. A timeout or exhausted guard fails verification and is never counted as a mutant.

The suite establishes only its constructed domains. Scratch allocation bounds, valid source and shift producers, indirect or modified-code entries, native VGA timing, and asynchronous IRQ ownership remain open.
